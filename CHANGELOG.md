# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-01

### Изменено

- **Лимит ботов считает одновременно работающих ботов**, а не всех уникальных за
  месяц. Бот занимает место, пока обращается к шлюзу, и освобождает его, промолчав
  дольше `ACTIVE_BOT_WINDOW` (новая настройка, по умолчанию 300 с). Активность
  хранится в `active_bots.last_seen`, поэтому лимит переживает рестарт узла и общий
  для нескольких узлов. Поле `Limits.monthly_bots` переименовано в `Limits.active_bots`.

### Исправлено

- Бот, получивший `402` по лимиту ботов, записывался в боты проекта, и его
  следующий запрос проходил — лимит обходился повторной попыткой.

### Безопасность

- Маскировка токенов ботов и ключей проектов в каждой записи лога: в любом логгере,
  при любой настройке логирования и в тексте исключений. Раньше защита держалась
  только на том, что логгеры httpx и httpcore подняты до `WARNING`.

### Добавлено

- Миграция `003_bot_activity.sql`: индекс по `active_bots.last_seen`.
- Пример редиректа `www` → основной домен в `deploy/Caddyfile`.

## [1.0.0] — 2026-09-26

Первый открытый выпуск шлюза, который работает в
[tg-relay.scriptora.ru](https://tg-relay.scriptora.ru).

### Добавлено

- Прозрачное проксирование Bot API: потоковая передача, long polling, загрузка и скачивание файлов.
- Проекты и ключи в PostgreSQL, CLI `tg-relay`, автономный режим без базы.
- Лимиты тарифа: запросы в секунду, боты и трафик в месяц.
- Почасовая статистика, журнал ошибок, «последний запрос» проекта.
- Метрики Prometheus, JSON-логи, `/healthz`, `/readyz`, корректная остановка.
